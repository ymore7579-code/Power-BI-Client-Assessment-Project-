# Power BI Client Assessment Project – E-Commerce Cosmetic Brand

## Project Overview

This project is a **Power BI Client Assessment Project** based on an **E-Commerce Cosmetic Brand**.

The project focuses on cleaning, transforming, analyzing, and visualizing business data to create interactive dashboards for management and business decision-making.

The dataset covers the period **2022–2026** and contains information related to sales, customers, products, campaigns, advertising, discounts, taxes, and revenue.

---

##  Project Objectives

- Clean and transform raw business data.
- Handle duplicate records and inconsistent values.
- Correct spelling mistakes and data-quality issues.
- Create calculated columns and measures.
- Analyze revenue, orders, customers, products, brands, and campaigns.
- Build interactive Power BI dashboards.
- Identify sales and product performance trends.
- Provide an executive-level view of business performance.

##  Data Cleaning & Transformation

The project includes several data-preparation activities such as:

- Removing duplicate Product IDs.
- Removing duplicate Order IDs.
- Correcting spelling mistakes such as `Instgram` → `Instagram`.
- Cleaning incorrect product names.
- Handling null and inconsistent values.
- Standardizing status values.
- Creating custom columns.
- Creating calculated columns and measures.
- Preparing data for analysis and visualization.
